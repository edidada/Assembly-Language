## 推荐方案：VS Code + MASM/TASM 插件

### 1. 安装插件

```powershell
code --install-extension xsro.masm-tasm
```

这个插件下载量 30 万+，就是专门为 DOS 下的 MASM/TASM 教学写的，支持：

- MASM/TASM 语法高亮、格式化、悬停提示
- 右键 **Run ASM Code**：自动汇编、链接、在 DOSBox 里运行
- 右键 **Debug ASM Code**：自动调用 DOSBox 里的 `DEBUG`
- 内置 MASM 5.00 工具链，不需要先解压 DOS.rar

### 2. 配置 DOSBox 路径

VS Code 设置里加入：

```json
{
  "masmtasm.ASM.assembler": "MASM-v5.00",
  "masmtasm.command.dosbox": "\"C:\\Program Files (x86)\\DOSBox-0.74-3\\DOSBox.exe\""
}
```

`masmtasm.ASM.assembler` 默认是 TASM，要改成 `MASM-v5.00` 才和书里一致。

### 3. 使用

打开 `源代码/ch6/p63.asm` 这类文件，在编辑器里右键：

- **Run ASM Code** → 直接运行
- **Debug ASM Code** → 进入 `DEBUG`，可以用 `r`、`u`、`t`、`d`、`g` 等命令

如果右键没有菜单，先把文件语言模式切到 **Assembly**。

## 手动方案：DOSBox 里用 MASM 5.0

想真正理解书里的 `masm`、`link`、`debug` 流程，可以手动做。

### 解压 DOS.rar

这台机器上的 `tar` 能直接解 RAR：

```powershell
tar -xf DOS.rar -C D:\develops\tools
```

解压后会有 `D:\develops\tools\DOS\DOSBox.exe` 和 `DOS\masm\`。

### 启动 DOSBox 并挂载

```powershell
& 'C:\Program Files (x86)\DOSBox-0.74-3\DOSBox.exe'
```

在 DOSBox 窗口里：

```dos
mount c D:\develops\git\github\asm\Assembly-Language\源代码
mount d D:\develops\tools\DOS\masm
c:
set PATH=%PATH%;D:\
cd ch6
masm p63.asm;
link p63.obj;
p63.exe
debug p63.exe
```

说明：

- `masm xxx.asm;` 结尾的分号表示后面全部用默认值
- `link xxx.obj;` 生成 `.exe`
- `debug xxx.exe` 进入调试，常用命令：
  - `r` 查看/修改寄存器
  - `u` 反汇编
  - `t` 单步执行
  - `p` 跳过子程序
  - `d` 查看内存
  - `g` 运行到断点

## 不建议用于本书的工具

- **Visual Studio 2026**：`ml64` 是 64 位 Windows 汇编工具链，不能生成和运行书里的 16 位 DOS 程序。
- **NASM**：语法和 MASM 不同，适合写引导扇区、DOS `.COM` 或自己新写的程序，不适合直接编译本书源码。
- **`D:\develops\tools\MASM_6_x`**：`ML.EXE` 能运行，但 `LINK.EXE` 是 16 位程序，64 位 Windows 不能直接执行；要链接 DOS `.exe` 还是得进 DOSBox。

## 另外修正了一个兼容性问题

之前 CI 里为了 JWasm 加的 `option nokeyword` 是 MASM 6+ 指令，直接用书里的 MASM 5.0 会报错。现在已改成：

```asm
ifdef @Version
option nokeyword:<c>
endif
```

MASM 5.0 会跳过这条指令，JWasm/MASM 6+ 才会执行。GitHub Actions 最新运行仍然全绿：

- 66 个源文件全部汇编通过
