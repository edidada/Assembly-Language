# ch5

compare.asm
这段代码来自王爽《汇编语言》，主要用于理解 8086 CPU 如何通过内存地址读取数据，以及段寄存器 DS 的作用。

它的核心操作是：从内存中连续读取 4 个字节，分别放入 AL、BL、CL、DL 寄存器。

## 一、逐行解释

```
assume cs:code

code segment
    mov ax,2000h
    mov al,[0]
    mov bl,[1]
    mov cl,[2]
    mov dl,[3]

    mov ax,4c00h
    int 21h
code ends
end
```

| 汇编代码             | 含义                        |
| ---------------- | ------------------------- |
| `assume cs:code` | 告诉汇编器，代码段寄存器 CS 对应 code 段 |
| `code segment`   | 定义一个名为 code 的段            |
| `mov ax,2000h`   | 将十六进制数 2000H 放入 AX        |
| `mov al,[0]`     | 读取内存 DS:0000 处的一个字节到 AL   |
| `mov bl,[1]`     | 读取内存 DS:0001 处的一个字节到 BL   |
| `mov cl,[2]`     | 读取内存 DS:0002 处的一个字节到 CL   |
| `mov dl,[3]`     | 读取内存 DS:0003 处的一个字节到 DL   |
| `mov ax,4c00h`   | 设置 DOS 程序退出功能号            |
| `int 21h`        | 调用 DOS 中断，结束程序            |
| `code ends`      | 结束 code 段定义               |
| `end`            | 告诉汇编器源程序结束                |

## 二、重点：`mov al,[0]` 是什么意思？

8086 CPU 使用 段地址 + 偏移地址 访问内存。

物理地址计算公式：

\\[ 物理地址=段地址\times16+偏移地址 \\]

例如，假设：

```
DS = 1000H
```

那么：

8086 内存访问示意图

假设 DS=1000H，则实际访问物理地址 10000H～10003H。

所以：

```
mov al,[0]   ; AL = 内存[DS:0000]
mov bl,[1]   ; BL = 内存[DS:0001]
mov cl,[2]   ; CL = 内存[DS:0002]
mov dl,[3]   ; DL = 内存[DS:0003]
```

注意：方括号 `[ ]` 表示访问内存，不是直接赋值。

```
mov al,3     ; AL = 3
mov al,[3]   ; AL = 内存中偏移地址3处的字节
```

两者完全不同。

## 三、这段代码有一个关键问题

```
mov ax,2000h
```

这条指令只修改 AX，没有修改 DS。

因此后面的：

```
mov al,[0]
```

并不是读取物理地址 `20000H`，而是读取当前 `DS:0000` 指向的内存。

如果希望从 `2000:0000` 开始读取，应当这样写：

```
assume cs:code

code segment
    mov ax,2000h
    mov ds,ax       ; DS = 2000H

    mov al,[0]      ; 读取 20000H
    mov bl,[1]      ; 读取 20001H
    mov cl,[2]      ; 读取 20002H
    mov dl,[3]      ; 读取 20003H

    mov ax,4c00h
    int 21h
code ends
end
```

为什么不直接写 `mov ds,2000h`？

因为 8086 不支持将立即数直接送入段寄存器 DS，必须借助 AX 等通用寄存器。

## 四、类比 C 语言

如果将 DS 看成内存基地址，可以近似理解为：

```
#include <stdint.h>

void example(uint8_t *memory)
{
    uint8_t al = memory[0];
    uint8_t bl = memory[1];
    uint8_t cl = memory[2];
    uint8_t dl = memory[3];
}
```

这里 `memory` 相当于由 DS 指定的段基址，`[0]`、`[1]` 等是偏移地址。

但 C 代码只是逻辑类比，并不完全等同于真实的 8086 寄存器操作。

## 五、还要理解 AX 与 AL 的关系

8086 的 AX 是 16 位寄存器，可以拆成两个 8 位寄存器：

执行：

```
mov ax,2000h
```

结果：

```
AX = 2000H
AH = 20H
AL = 00H
```

接着：

```
mov al,[0]
```

假设内存中的数据是 `35H`，那么：

```
AH = 20H
AL = 35H
AX = 2035H
```

修改 AL 会影响 AX 的低 8 位，但不会影响 AH。

总结： 这段代码重点考察三个知识点：`[偏移地址]` 表示内存访问、DS 决定默认数据段、AX 和 AL 之间存在高低位关系。

还有一个值得注意的问题：在王爽《汇编语言》中，为什么 `mov ax,[0]` 和 `mov al,[0]` 读取的数据长度不同？这是理解 8086 字节、字以及小端存储 的关键。
