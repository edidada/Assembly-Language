# book
王爽《汇编语言》讲的这些指令和概念，基本覆盖了 8086 CPU 如何执行程序、访问内存、实现循环、调用函数、处理中断 的核心机制。

其中，`jmp`、`call`、`ret`、`int`、`iret` 都与 CPU 执行流程的改变 有关；`cmp`、条件转移指令用于判断；`push`、`pop` 用于栈操作；`loop` 用于循环；分段和寻址方式则解决内存访问问题。

下面按照书中的 8086 16 位汇编语法，逐个介绍，并与 C 语言对应。

## 一、11 类指令和概念总览

| 指令或概念          | 核心作用      | C 语言类比          |
| -------------- | --------- | --------------- |
| `jmp`          | 无条件跳转     | `goto`          |
| 条件转移           | 满足条件才跳转   | `if`            |
| `call`         | 调用子程序     | 函数调用            |
| `ret`          | 从子程序返回    | `return`        |
| `push` / `pop` | 栈数据存取     | 栈操作             |
| `int`          | 触发软件中断    | 系统调用（部分场景）      |
| `iret`         | 从中断处理程序返回 | 中断返回            |
| `cmp`          | 比较两个操作数   | `a == b` 等比较    |
| `loop`         | 按 CX 计数循环 | `for` / `while` |
| 分段             | 组织和定位内存   | 内存地址空间          |
| 寻址方式           | 指定操作数的位置  | 变量、指针、数组        |

## 二、逐个讲解

### 1. `jmp`：无条件跳转

`jmp`（Jump）用于修改 CPU 下一条要执行的指令位置。

```
mov ax,1

jmp next

mov ax,2       ; 被跳过

next:
    add ax,3
```

执行结果：`AX = 4`。

对应 C 语言：

```
int ax = 1;
goto next;
ax = 2;

next:
ax += 3;
```

CPU 本质： `jmp` 会改变指令指针 IP，远跳转还可能改变 CS，从而改变后续取指位置。

### 2. 条件转移指令：实现 `if`

常见条件跳转指令：

| 指令            | 含义        | 条件               |
| ------------- | --------- | ---------------- |
| `je` / `jz`   | 相等 / 结果为零 | ZF = 1           |
| `jne` / `jnz` | 不相等 / 非零  | ZF = 0           |
| `ja`          | 无符号大于     | CF = 0 且 ZF = 0  |
| `jb`          | 无符号小于     | CF = 1           |
| `jg`          | 有符号大于     | ZF = 0 且 SF = OF |
| `jl`          | 有符号小于     | SF ≠ OF          |
| `jc`          | 有进位       | CF = 1           |

示例：

```
mov ax,10
cmp ax,20
jl smaller

mov bx,1
jmp done

smaller:
    mov bx,2

done:
```

结果：`BX = 2`。

C 语言：

```
int bx;
if (10 < 20)
    bx = 2;
else
    bx = 1;
```

注意 `jl` 是有符号比较，`jb` 是无符号比较。

### 3. `call`：调用子程序

`call`（Call Procedure）用于调用一个子程序。

```
mov ax,10

call double_ax

; 返回这里继续执行
jmp done

double_ax:
    add ax,ax
    ret

done:
```

结果：`AX = 20`。

对应 C 语言：

```
int double_ax(int x)
{
    return x * 2;
}

int main(void)
{
    int ax = double_ax(10);
    return 0;
}
```

CPU 本质：

`call` 不只是跳转，还会把返回地址压入栈。

CALL 调用过程

### 4. `ret`：从子程序返回

`ret`（Return）会从栈中取出返回地址，继续执行调用者后面的指令。

```
func:
    mov ax,100
    ret
```

对于普通的近调用：

- `call`：将返回 IP 压栈，跳转到子程序。
- `ret`：从栈中弹出 IP，返回调用位置。

对于远调用 `call far`，还涉及 CS，通常使用 `retf` 返回。

这就是现代 C/C++ 函数调用机制的基础之一。

### 5. `push` / `pop`：栈指令

8086 的栈通常向低地址方向增长。

```
mov ax,1234h
push ax

mov ax,5678h
pop bx
```

执行结果：

- AX = 5678H
- BX = 1234H

因为 `push ax` 把 AX 的旧值保存到了栈中，`pop bx` 又把它取出。

8086 栈的变化（示意）

初始PUSH AXPOP BX

假设初始 SP = 1000H

8086 中：

```
push ax    ; SP = SP - 2，写入一个字
pop bx     ; 读取一个字，SP = SP + 2
```

栈段地址由 SS 指定，栈顶偏移由 SP 指定，即 `SS:SP`。

### 6. `int`：软件中断

`int`（Interrupt）用于主动触发指定中断向量对应的处理程序。

例如 DOS：

```
mov ax,4c00h
int 21h
```

作用：通过 DOS 的 21H 中断、4CH 功能退出程序，返回码为 0。

CPU 执行 `int n` 时，8086 会保存 FLAGS、CS、IP 等返回上下文，并跳转到中断向量表指定的处理程序。

`int` 不完全等于系统调用：它也可以用于其他软件中断用途；而现代操作系统的系统调用也不一定使用 `int`。

### 7. `iret`：中断返回

`iret`（Interrupt Return）用于从中断处理程序返回。

```
my_handler:
    ; 处理中断
    iret
```

在 8086 中，`iret` 会依次从栈中恢复：

1. IP
2. CS
3. FLAGS

与 `ret` 不同，`iret` 不仅恢复执行地址，还恢复标志寄存器。

这也是为什么普通函数返回使用 `ret`，而中断处理程序返回使用 `iret`。

### 8. `cmp`：比较指令

`cmp`（Compare）本质上执行一次减法，但不保存减法结果，只更新 FLAGS 中相关状态位。

```
mov ax,10
mov bx,20

cmp ax,bx
```

CPU 相当于计算：

\\[ 10-20=-10 \\]

但 AX 仍然是 10，BX 仍然是 20。

`cmp` 会影响 ZF、CF、SF、OF 等标志位，后面的条件转移指令读取这些标志位。

```
cmp ax,bx
je equal
```

表示：如果 AX 和 BX 相等，就跳转到 `equal`。

### 9. `loop`：循环指令

`loop` 使用 CX 寄存器作为计数器。

```
mov cx,5
mov ax,0

s:
    add ax,2
    loop s
```

执行结果：AX = 10。

`loop s` 的工作原理：

1. CX 减 1。
2. 如果 CX 不等于 0，跳转到 `s`。
3. 如果 CX 等于 0，继续向下执行。

对应 C 语言：

```
int ax = 0;

for (int cx = 5; cx != 0; --cx) {
    ax += 2;
}
```

注意，8086 的 `loop` 是先递减再判断，因此如果 CX 初始为 0，会发生 16 位计数回绕，而不是直接跳过循环。

### 10. 分段：Segment

8086 CPU 有 20 位物理地址总线，可以访问 1 MiB 的物理地址空间，但通用寄存器只有 16 位。

因此它使用：

\\[ 物理地址 = 段地址 \times 16 + 偏移地址 \\]

例如：

```
mov ax,2000h
mov ds,ax
mov bx,1000h

mov ax,[bx]
```

这里的内存访问默认使用 DS 段。

- DS = 2000H
- BX = 1000H
- 物理地址 = 20000H + 1000H = 21000H

`mov ax,[bx]` 会读取物理地址 21000H 开始的两个字节，组成一个 16 位值存入 AX。

8086 常用段寄存器：

| 寄存器 | 用途  |
| --- | --- |
| CS  | 代码段 |
| DS  | 数据段 |
| SS  | 栈段  |
| ES  | 附加段 |

这里的分段是 8086 实模式地址机制，不要直接等同于现代 ELF/PE 文件中的节或段。

### 11. 寻址方式：Addressing Modes

寻址方式就是告诉 CPU：操作数从哪里来？

常见形式：

| 寻址方式   | 汇编代码               | 含义              |
| ------ | ------------------ | --------------- |
| 立即数    | `mov ax,1234h`     | 常数直接写入 AX       |
| 寄存器    | `mov ax,bx`        | BX 的值写入 AX      |
| 直接内存   | `mov ax,[1000h]`   | 读取 DS:1000H     |
| 寄存器间接  | `mov ax,[bx]`      | 读取 DS:BX        |
| 寄存器相对  | `mov ax,[bx+2]`    | 读取 DS:(BX+2)    |
| 基址变址   | `mov ax,[bx+si]`   | 读取 DS:(BX+SI)   |
| 相对基址变址 | `mov ax,[bx+si+4]` | 读取 DS:(BX+SI+4) |

例如 C 语言：

```
int arr[10];
int x = arr[3];
```

在汇编层面，数组元素访问通常就是利用 基地址 + 索引偏移 计算内存地址。

## 三、这些指令之间有什么联系？

可以按照四组来理解：

控制流程

`jmp`、条件跳转、`loop`

决定下一条指令执行哪里

函数调用

`call`、`ret`、`push`、`pop`

调用、返回与保存上下文

比较和中断

`cmp`、`int`、`iret`

状态判断与中断控制转移

内存访问

分段、寻址方式

确定数据和指令的位置

## 四、学习顺序建议

按照王爽《汇编语言》的学习思路，建议：

寄存器与内存 → 分段与寻址 → 栈 → cmp/条件转移 → loop → jmp → call/ret → int/iret。

其中最值得深入理解的是：

- `CS:IP` 如何控制 CPU 取指令。
- `SS:SP` 如何实现栈。
- `FLAGS` 如何让 `cmp` 和条件跳转协同工作。
- `call/ret` 如何通过栈实现函数调用。
- `int/iret` 如何保存与恢复程序执行现场。

这些机制不仅适用于理解 8086，也能帮助你阅读现代 x86-64 反汇编、理解 C/C++ 函数调用、GDB 栈回溯以及操作系统的中断处理。

尤其要记住：汇编语言中的 `if`、`for`、函数调用，并不是 CPU 天生就认识的高级结构，而是由比较、跳转、寄存器和栈等底层机制组合实现的。
